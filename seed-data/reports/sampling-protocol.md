# Before recording a sample

1. Confirm the site code and UTC timestamp.
2. Check calibration status for the dissolved oxygen and turbidity probes.
3. Rinse the probe with site water, then record temperature, pH, turbidity,
   dissolved oxygen, and weather.
4. If a value looks unusual, collect a duplicate and add a field note.

The notebook may suggest what to compare, but the researcher owns the final
interpretation.
